# R3-5 实验计划：重缩放锥投影的 GPU 实用性

## 审稿意见

> 重缩放二阶锥和指数锥投影在数学上很有意义，但其 GPU 实用性尚不明确，因为二分搜索、归约、指数运算、复杂分支、可变迭代次数和同步都可能降低 GPU 效率。论文应报告二分迭代次数、投影时间占总运行时间的比例、固定与自适应二分停止规则的比较，以及未缩放、对角缩放和标量缩放锥之间的消融实验。

针对该意见，计划完成以下四个实验。

## 实验一：二分投影的平均向量计算量

### 目的

统计使用 diagonal rescaling 后，每完成一次锥投影平均需要计算多少次向量—向量乘法，以及相对基准投影多计算了多少次。

这里的一次“向量—向量乘法”指对整个锥向量完成一次逐元素乘法并归约为标量，即一次内积型运算。不再区分 Newton 步、区间扩张、启发式候选或其他内部路径。

### 方法

在投影代码中加入一个简单计数器，实际执行一次向量—向量乘法就加一。设共有 (M) 个锥，PDHG 共执行 (T) 次迭代，第 (t) 次 PDHG 迭代中第 (i) 个锥使用了 (N_{t,i}) 次向量—向量乘法，则平均计算次数定义为

\[
\bar N_{\mathrm{vv}}
=
\frac{1}{MT}
\sum_{t=1}^{T}\sum_{i=1}^{M}N_{t,i}.
\]

也就是先对一次 PDHG 迭代中的所有锥求和，再对全部 PDHG 迭代求和，最后除以锥总数 (M) 和 PDHG 迭代次数 (T)。该指标表示“每个锥、每次 PDHG 迭代平均需要多少次向量—向量乘法”。

对同一批输入分别运行：

- 基准投影；
- diagonal rescaling 后的投影。

报告

\[
\bar N_{\mathrm{extra}}
=
\frac{1}{MT}
\sum_{t=1}^{T}\sum_{i=1}^{M}
\left(
N_{t,i}^{\mathrm{diagonal}}
-N_{t,i}^{\mathrm{baseline}}
\right).
\]

对于 SOC，基准是具有显式解的未缩放 SOC 投影；对于指数锥，基准是现有未缩放指数锥投影。

计数器版本只用于统计，正式运行时间仍使用未插桩的 projection kernel。

### 输出

| 锥类型 | 锥维度 | 平均基准次数 | 平均 diagonal 次数 | 平均额外次数 |
|:---|---:|---:|---:|---:|

## 实验二：投影时间占总运行时间的比例

### 目的

统计 cuPDCS 在实际求解过程中花在锥投影上的时间比例：

\[
R_{\mathrm{proj}}
=
\frac{T_{\mathrm{projection}}}
{T_{\mathrm{solve}}}.
\]

### 方法

复用现有代码中的 `time_proj` 统计位置，但先确认它记录的是 GPU 实际执行时间，而不只是异步 kernel launch 时间。可以在原有 projection wrapper 中使用 CUDA events；总时间使用从 PDHG 主循环开始到终止的同步墙钟时间。

在论文已有的三类应用上运行：

- Fisher market：主要包含指数锥；
- Lasso：包含高维 SOC；
- Multi-period portfolio：包含多个 SOC。

使用与论文相同的问题、seed 和终止容差。分别报告原始投影、dual/slack 投影以及二者合计所占的时间比例。

### 输出

| 应用 | 问题规模 | 终止容差 | 总求解时间 | 投影时间 | 投影占比 |
|:---|:---|---:|---:|---:|---:|

## 实验三：固定与自适应二分停止规则

### 目的

比较固定 projection tolerance 与 adaptive projection tolerance，并验证加入 adaptive tolerance 后，计算投影所需的向量—向量乘法次数是否减少。

### 方法

- **固定 tolerance：** 在全部 PDHG 迭代中使用同一个严格的投影残差容差；
- **Adaptive tolerance：** PDHG 初期使用较宽松的投影容差，并根据当前 KKT error 逐渐收紧到预设下限。

实现使用三态选项 `adaptive_projection_tolerance`：

- `true`：从 `1e-7` 开始，根据平均 KKT error 单调收紧到 `1e-14`；
- `false`：固定为 `1e-12`；
- `nothing`（默认）：保留修改前的 legacy 策略，便于复现实验和回归比较。

除 projection tolerance 外，两个版本使用完全相同的问题、seed、初始点、缩放方式和求解器参数。

设第 \(t\) 次 PDHG 迭代中共有 \(M_t\) 个锥投影事件，第 \(i\) 个锥使用了 \(N_{t,i}\) 次向量—向量乘法。首先统计每个锥、每次 PDHG 迭代的平均次数：

\[
\bar N_{\mathrm{vv}}
=
\frac{
\sum_{t=1}^{T}\sum_{i=1}^{M_t}N_{t,i}
}{
\sum_{t=1}^{T}M_t
}.
\]

若每次 PDHG 迭代的锥数量固定为 \(M\)，分母就是 \(MT\)。

Adaptive tolerance 带来的平均计算量下降比例定义为

\[
R_{\mathrm{save}}^{\mathrm{avg}}
=
1-
\frac{\bar N_{\mathrm{vv}}^{\mathrm{adaptive}}}
{\bar N_{\mathrm{vv}}^{\mathrm{fixed}}}.
\]

同时统计整个求解过程的向量—向量乘法总次数：

\[
N_{\mathrm{vv}}^{\mathrm{total}}
=
\sum_{t=1}^{T}\sum_{i=1}^{M_t}N_{t,i},
\]

以及总计算量下降比例

\[
R_{\mathrm{save}}^{\mathrm{total}}
=
1-
\frac{N_{\mathrm{vv,adaptive}}^{\mathrm{total}}}
{N_{\mathrm{vv,fixed}}^{\mathrm{total}}}.
\]

同时报告 projection tolerance 随 PDHG 迭代的变化、PDHG 迭代次数、投影时间、总求解时间和最终 KKT error。两个版本必须达到相同的最终终止精度，才能比较计算量和时间。

### 输出

| 应用 | 规则 | PDHG 迭代数 | 每锥每迭代平均向量乘法次数 | 向量乘法总次数 | 投影时间 | 总求解时间 | 最终 KKT |
|:---|:---|---:|---:|---:|---:|---:|---:|

该实验的主要结论是 adaptive tolerance 相对固定 tolerance 减少了多少平均投影计算量和整个求解过程的总计算量，以及这种减少是否转化为更短的投影时间和总求解时间。

## 实验四：未缩放、标量缩放和对角缩放的效能比较

### 目的

比较三种预处理方式对投影成本、PDHG 迭代次数和端到端求解时间的影响：

1. **未缩放：** 不执行 Ruiz rescaling 和 Pock--Chambolle rescaling；
2. **对角缩放：** 使用当前逐坐标的 Ruiz 和 Pock--Chambolle scaling；
3. **标量缩放：** 仍执行 Ruiz 和 Pock--Chambolle scaling，但同一个锥内的所有坐标使用同一个缩放标量。

前两种方式已经存在，主要新增第三种标量缩放方式。

### 标量缩放的实现

新增一种 preprocessing mode，例如：

```julia
rescaling_method = :ruiz_pock_chambolle_scalar_cone
```

同时提供独立布尔选项，便于在同一个 rescaling method 下做消融：

```julia
scalar_cone_rescaling = true
```

默认值为 `false`，即保留原逐坐标 diagonal rescaling。显式 method
`:ruiz_pock_chambolle_scalar_cone` 等价于
`rescaling_method = :ruiz_pock_chambolle` 加
`scalar_cone_rescaling = true`；二者任一启用即可。该布尔选项也可与
`:ruiz` 或 `:pock_chambolle` 单独组合。

当前 Ruiz 和 Pock--Chambolle 代码先得到逐坐标的候选缩放因子：

```text
variable_rescaling
constraint_rescaling_G
```

在调用 `scale_data!` 之前，按照 `primal_sol` 和 `dual_sol` 中记录的锥分块进行归并。对每个 SOC、rotated SOC 或指数锥块 \(B\)，将块内所有候选缩放因子替换为同一个值：

\[
s_B=\max_{j\in B}s_j,
\qquad
s_j\leftarrow s_B,\quad j\in B.
\]

这里使用块内最大值，是因为它与 Ruiz 的 \(\ell_\infty\) 缩放原则一致，对 Pock--Chambolle scaling 也提供保守的共同尺度。非负锥中的每个标量仍可视为一个一维锥，因此不需要额外处理。

该锥块归并需要在以下两个位置分别执行：

1. Ruiz 的每一轮中，在计算完 row/column scaling、调用 `scale_data!` 之前；
2. Pock--Chambolle scaling 中，在计算完 row/column scaling、调用 `scale_data!` 之前。

这样每一轮应用到同一锥的因子都是常数，因此累计的 `Dr_product` 和 `Dl_product` 在该锥内也始终保持为同一个标量。后续 `scale_preconditioner!` 应将对应的 `primalConstScale` 或 `dualConstScale` 识别为 `true`：SOC 使用现有 constant-scale projection path；指数锥由于 \(\alpha K_{\exp}=K_{\exp}\)，可使用未缩放指数锥投影。

需要增加两个简单检查：

- preprocessing 后，同一锥块内累计 scaling 的最大值与最小值相同；
- 三种 scaling 下恢复到原问题后的解都通过相同的 KKT 终止条件。

### 实验一/三计数器接口

统计运行前后使用：

```julia
PDCS_GPU.enable_projection_work_profile!(scope = :pdhg_iterations)
result = solve_application()
work = PDCS_GPU.disable_projection_work_profile!()
```

`scope = :pdhg_iterations` 只统计每次 PDHG step 的 primal/dual 投影对，
与上面的 (MT) 定义一致；`scope = :all` 可另行统计终止检查、restart 和
infeasibility check 触发的额外投影。`work.by_cone` 按锥类型、锥维度及 baseline/diagonal path 给出实际
projection event 数、向量—向量乘法归约总次数和每次投影平均次数。
grid-wise projection 在统计模式下会改走有插桩的 block-wise kernel；因此
该模式只用于操作计数，所有运行时间必须关闭计数器后用 production kernel
另跑一遍。

### 实验方法

在完全相同的问题、seed、初始点、终止容差和 time limit 下分别运行三种 scaling。使用论文中的 Fisher market、Lasso 和 Multi-period portfolio 实例。

报告以下指标：

- preprocessing 时间；
- PDHG 迭代次数；
- 单次迭代平均投影时间；
- 投影时间占比；
- 总求解时间；
- 最终 primal error、dual error 和 relative gap。

### 输出

| 应用 | 缩放方式 | PDHG 迭代数 | 平均投影时间 | 投影占比 | 总求解时间 | 最终 KKT |
|:---|:---|---:|---:|---:|---:|---:|

该实验应同时说明两件事：diagonal rescaling 是否增加了每次投影的成本，以及这种额外成本是否被更少的 PDHG 迭代和更短的总求解时间抵消。
